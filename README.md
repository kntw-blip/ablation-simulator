# ABL Sim — 3Dマッピング・カテーテルアブレーション シミュレータ

不整脈アブレーションの教育用Webシミュレータです。カテーテル操作で心腔の3Dジオメトリーを作成（FAM）し、
心内心電図・12誘導心電図とLAT／電位マップから回路・起源を同定して、RF・クライオ・パルスフィールド（PFA）で治療します。

> 教育用のシミュレーションです。実際の診療判断には使用しないでください。特定メーカーの装置を模したものではありません。

## 収載している不整脈

| シナリオ | 機序 | 誘発 | 治療目標 |
|---|---|---|---|
| 通常型心房粗動 | 三尖弁輪を反時計回りに旋回するマクロリエントリー（CL約250 ms、2:1伝導） | CS近位からのS1S2・バースト | CTIの貫壁性線状焼灼・ブロックライン |
| 発作性心房細動 | 肺静脈スリーブ内の異所性興奮（トリガー／ドライバー）と左房の不均一な不応期 | イソプロテレノール＋CSバースト | 4本の肺静脈隔離 |
| AVNRT（slow-fast） | 二重房室結節伝導路（AHジャンプ約100 ms、CL約356 ms） | HRAからのS1S2 | Koch三角下部での遅伝導路焼灼 |
| WPW症候群 | 僧帽弁輪側壁の顕性副伝導路（δ波、ORT CL約335 ms） | HRAからのS1S2 | 副伝導路付着部の焼灼（δ波消失） |
| 心室期外収縮 | 右室流出路中隔側の自動能（三段脈、左脚ブロック型・下方軸） | 自発（イソプロテレノールで増加） | 最早期興奮部位／ペースマップ一致部位の焼灼 |

## 主な機能

- **初心者モード**：シナリオ開始時に選択。画面各部の操作説明と、疾患ごとの手順ガイド（「やること」と、電位・所見の「見るポイント」）を表示し、達成すると自動で次のステップへ進みます。焼灼部位は解剖的な目安までを示します。

- **カテーテル**：HRA（高位側壁・低位側壁・右心耳・高位中隔から選択）、Halo 20極（三尖弁輪周囲）、His、RV（心尖部／中隔／流出路）、CS 10極（挿入深度可変）。アブレーションカテ（4極・接触圧センサー）と20極星形マッピングカテは、3D画面で壁をタップ（クリック）するとその部位へ移動し、矢印で位置を微調整、押す／緩めるで接触圧を調整します。左房・左室をタップすると経中隔アプローチになります。
- **CTIブロックの証明**：HRAを低位側壁に置き、CS入口部ペーシングで低位側壁までの伝導時間延長（例 95→216 ms）、低位側壁ペーシングでCS入口部までの延長を確認できます。Haloでは衝突型から反時計回り一方向性への興奮順序の変化が見られます。
- **FAM**：カテーテルが通過した血液腔のボクセルから表面を再構成します（答えの解剖は「解剖ガイド」で表示可能）。
- **マッピング**：接触電極から1拍ごとにLAT・バイポーラ電位を取得し、LAT・電位・伝播（propagation）マップを表示。基準（CS 9-10 / QRS onset）とWOIを設定できます。
- **心電図**：心筋の膜電位勾配（グラフラプラシアン）を電流源として、心内電位（単極・双極）と12誘導を合成します。キャリパー計測・フリーズ・掃引幅変更に対応。
- **刺激装置**：連続ペーシング、S1S2S3、バースト、推奨プロトコルでの自動誘発、PPI自動計測、PVCのペースマップ一致率。
- **焼灼**
  - RF：出力・接触圧・時間から焼灼深度／指標を推定。インピーダンス低下、スチームポップ、食道温上昇。
  - フォーカル・クライオ：クライオマッピング（−30℃、可逆）とアブレーション（−75℃）、カテーテル固着。
  - クライオバルーン：閉塞グレード（押し込み・傾き）、温度曲線、TTI、横隔神経ペーシングのCMAP監視、ダブルストップ。
  - PFA：フォーカル、および肺静脈用5スプライン（バスケット／フラワー、36°回転）。
  - 非貫壁性の焼灼は浮腫による一過性ブロックになり、「20分待機」後に再伝導します。
- **合併症**：完全房室ブロック、心タンポナーデ（スチームポップ・過大接触圧）、食道傷害、横隔神経麻痺、肺静脈狭窄リスク、冠動脈攣縮（PFA）、溶血（PFA多数回）。

## 操作

| 操作 | キー | 画面 |
|---|---|---|
| カテーテルを移動 | — | 3D画面の壁をタップ／クリック |
| 位置の微調整 | ↑ ↓ ← →（画面の向き基準） | 操作パッド |
| 接触圧を上げる／下げる | W / S | 押す／緩める |
| 壁から浮かす／戻す | F | 浮かす |
| マッピングカテのスプライン回転 | R | 回転 |
| 通電（開始／停止） | Space | 通電・焼灼タブ |
| 3D表示 | ドラッグで回転、ホイール／ピンチでズーム、右ドラッグで平行移動 | 視点ボタン（AP/LAO/RAO/PA/LL/下） |

肺静脈用デバイス（クライオバルーン・PFA）では、静脈をタップして標的を選び、押し込む／引く・傾きで位置を合わせ、「造影」で閉塞を確認します。

治療の成否は画面に常時表示しません。電位（興奮順序・伝導時間・再誘発）で判断し、「記録」タブの「手技終了・評価」で正解（現時点と浮腫回復後の予測）を確認します。

基本の流れ：

1. 「マップ」タブで新規マップを作成 → FAM記録ONで心腔内をなぞる（デモ用の自動FAMもあります）
2. ポイント自動取得をONにして、洞調律または頻拍中にLAT・電位を取得
3. 「刺激」タブで誘発 → 「焼灼」タブで治療 → 「20分待機」→ 再誘発で効果判定

## モデルの概要

- **解剖**：符号付き距離関数で右房（SVC・IVC・心耳）、左房（4本の肺静脈・心耳）、冠静脈洞、右室（流出路）、左室を定義し、Surface Netsでメッシュ化。弁輪・静脈は開口として切り出しています。
- **興奮伝播**：メッシュ頂点（約2.8万）を心筋セルとするイベント駆動型の伝播モデル。不応期の回復特性（restitution）、短い拡張期間での伝導遅延、房室結節の減衰伝導を持ちます。房室結節の速伝導路・遅伝導路、His束・脚・Purkinje、副伝導路は仮想ノードで表現し、心室は内膜・外膜の2層で貫壁性興奮を再現します。
- **電位**：心内電位は近傍の電流源を直接計算（遠方は空間ビンで近似）、体表面心電図はリードフィールドのラプラシアンを事前計算して求めます。
- **焼灼**：焼灼深度が局所壁厚（部位別：CTI 3.5 mm、肺静脈スリーブ 1–2 mm、心室 2 mm（心内膜下）など）を超えると伝導途絶、半分以上で浮腫による一過性ブロックとしています。

数値は教育目的の近似であり、実際の焼灼条件の推奨値ではありません。

## 開発

```bash
npm install
npm run dev      # 開発サーバ
npm test         # 5シナリオの「誘発→焼灼→停止→再誘発不能」を画面なしで検証
npm run build    # dist/ に静的ファイルを出力
```

ディレクトリ構成：

```
src/core/   シミュレーション本体（DOM非依存）
  anatomy.js      解剖のSDF定義
  tissue.js       心筋ノード・伝導系・部位別パラメータ
  sim.js          興奮伝播エンジン
  scenarios.js    不整脈シナリオと成功判定
  egm.js          心内電位・12誘導の合成
  catheter.js     カテーテル運動学と電極
  fam.js          FAM再構成とマップ補間
  ablation.js     RF／クライオ／PFAと合併症
  session.js      上記をまとめるセッション
src/ui/     3D表示（Three.js）と心電図表示
test/       ヘッドレスのシナリオテスト
```

`main` ブランチへのpushで `.github/workflows/deploy.yml` がテスト・ビルドし、GitHub Pagesへデプロイします。
初回のみ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定してください。
